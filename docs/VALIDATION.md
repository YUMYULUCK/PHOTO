## 真实 iPhone 必须验收

1. Safari 在线打开网站。用一张原版本已能处理的 HEIC 原片分别从相册及「文件」导入，记录型号、iOS 版本、来源、实际格式和处理状态。
2. 若相册提供 JPG，确认显示「当前照片以 JPG 格式导入」、原因与两个恢复入口，且没有处理成功或下载结果。
3. 按「照片 → 分享 → 选项 → 当前 → 存储到文件」重试。原片若本来是 JPG，不能通过改后缀解决。
4. 对兼容原片分别开关智能匹配，下载/分享副本，在照片 App 中确认可打开、摄影风格及质感/颗粒控件可用、方向与 HDR 正常。核对原片未被覆盖。
5. 混合多张 HEIC、JPG、PNG，确认拒绝文件不阻塞后续照片。切换语言后检查状态、帮助、品牌名称及底部署名。
6. 在线加载后关闭智能匹配，断网重开并处理兼容原片，确认离线和下载可用。
7. 在保留旧缓存的 Safari/主屏幕应用中在线刷新，确认出现新界面。不要先清除数据；随后断网重开，确认仍为新版。有队列时更新应提示刷新而不清空待下载结果。
